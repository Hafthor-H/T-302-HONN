# Software Design and Development (T-302-HONN)

This repository contains laboratory assignments completed for **Software Design and Development (Hönnun og smíði hugbúnaðar)** at Reykjavík University during Fall 2026.

The coursework focuses on software design principles, design patterns, dependency injection, software architecture, and containerization. The implementations are written in Python.

## Authors
- Hafþór Haugen
- Guðmundur A. Magnússon

## Contents

- **Lab 1 – Logging:** Implementation of console, file, and database logging using a shared interface.
- **Lab 2 – Design Principles:** Exercises involving code quality, error handling, and identifying design problems in existing code.
- **Lab 3 – SOLID, Observer & Decorator:** Applying SOLID principles to a shipment system and implementing the Observer and Decorator patterns in a weather monitoring application.
- **Lab 4 – Design Patterns:** Implementing Factory Method and Abstract Factory in a pizza ordering system, along with Command and Composite patterns for order validation.
- **Lab 5 – Dependency Injection:** Implementing dependency injection in a phone book application using interchangeable repositories and configurable dependencies.
- **Lab 6 – Software Architecture:** Exploring 3-Tier, Onion Architecture, and Vertical Slicing by restructuring an application.
- **Lab 7 – Docker:** Containerizing a Python application using Docker and Docker Compose, including database migrations.
